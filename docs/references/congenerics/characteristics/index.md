# foapy.congenerics.characteristics

The package provides characteristics for measuring properties of congeneric sequences grouped by element of the alphabet.

The table below summarizes per-symbol (plural) characteristics returning one value per congeneric group:

| Linear scale | | Logarithmic scale | |
|---|---|---|---|
| [Arithmetic Means](arithmetic_means.md) | $\left[ \Delta_{a_j} \right]$ | | |
| [Geometric Means](geometric_means.md) | $\left[ \Delta_{g_j} \right]$ | $\left[ g_j \right]$ | [Average Remotenesses](average_remotenesses.md) |
| [Volumes](volumes.md) | $\left[ V_j \right]$ | $\left[ G_j \right]$ | [Depths](depths.md) |
